## 2026-09-08 — Аудит репозиторію + створення claude/-документів

  файлом користувача `sun-ice-project-summary.md` (саммарі з іншого чату/проєкту).
- Знайдено і виправлено неточність саммарі: плитки **VRF** і **Теплові насоси** вже
  мають повну робочу реалізацію (парсинг Excel + рендер + кошик), а не заглушки
  "Скоро", як там стверджувалось. Реально заглушками лишаються 5 плиток: ККБ, Чиллери,

- Створено `claude/HANDOFF.md` (стартовий технічний огляд для нового чату) і цей файл —
  щоб контекст проєкту зберігався в самому git-репозиторії, а не тільки в окремому
  Claude Project, до якого новий чат може не мати доступу.

**Статус деплою:** нема що заливати з коду застосунку. Але два нові файли
(`claude/HANDOFF.md`, `claude/CHANGELOG.md`) потрібно залити в репозиторій — див.
інструкцію нижче.

**Кроки для користувача:**
1. Відкрити https://github.com/conditionerall-creator/sun-ice
2. Add file → Upload files

   `CHANGELOG.md` (створять папку `claude/` в репо автоматично)
